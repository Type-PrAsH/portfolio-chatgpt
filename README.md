# Prashant Agrawal — React Portfolio

A responsive, dark editorial-style portfolio built with React, Vite and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173).

## Customize before publishing

1. Open `src/main.jsx`.
2. Update `profile.email` to your real contact email.
3. Replace the project descriptions/links with your verified work. The SchedWise and video-editing entries are currently presented as concepts/portfolio samples.
4. Add your own project screenshots or video thumbnails if available.
5. Confirm the LinkedIn and GitHub links are correct.

## Build for deployment

```bash
npm run build
```

Deploy the generated `dist` directory to Vercel, Netlify or GitHub Pages.
